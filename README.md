# Echipa-7-3IE2025
# Agenda mea de filme 🎬

Acest proiect a fost realizat în cadrul disciplinei Rețele / Programare Internet din cadrul UVT. Aplicația reprezintă un site web static creat pentru gestionarea unei mici agende de filme. Utilizatorul poate vizualiza o listă de filme existente și poate căuta rapid un titlu în funcție de nume. De asemenea, aplicația permite filtrarea filmelor după gen, astfel încât navigarea să fie mai simplă și mai eficientă. În plus, pot fi adăugate filme noi, care sunt păstrate temporar în memoria paginii pe durata sesiunii. Proiectul ilustrează modul în care elementele de bază ale dezvoltării web – HTML, CSS și JavaScript – pot fi combinate pentru a realiza o interfață intuitivă chiar și fără un backend sau o bază de date persistentă.

## 2. Descriere proiect

Aplicația afișează o listă de filme predefinite și permite:

- căutarea filmelor după titlu;
- filtrarea filmelor după gen (Acțiune, SF, Dramă, Comedie, Animație);
- vizualizarea detaliilor unui film selectat;
- adăugarea de filme noi printr-un formular.

Datele introduse de utilizator sunt păstrate doar în memoria paginii (nu se salvează în baza de date sau fișiere).

Modificare făcută de membrul 4.ALexandrescu Beatrice

---

## 3. Tehnologii utilizate

- **HTML5** – structura paginilor `index.html` și `about.html`
- **CSS3** – stilizare și layout responsive în `style.css`
- **JavaScript (ES6)** – logica aplicației în `script.js`
  - popularea listei de filme
  - filtrarea/căutarea
  - afișarea detaliilor
  - adăugarea de filme noi

---

## 4. Structura proiectului

- `index.html` – pagina principală (lista de filme, filtre, formular de adăugare)
- `about.html` – informații despre proiect
- `style.css` – stilul vizual al aplicației
- `script.js` – logica de funcționare (manipulare DOM, filtre, formular)

---

## 5. Cum se rulează

1. Se descarcă/clonează repository-ul.
2. Se deschide fișierul `index.html` în browser (Chrome, Edge, Firefox etc.).
3. Nu este nevoie de server sau baze de date – proiectul este 100% static.
